Name it and it breathes

Six dragons, one word

A dragon is a drawing whose name happens to be fire dragon. The name is the wish — it flies, it breathes fire. The shape is everything else: bigger is tougher, spikes do damage, more legs run faster, closed loops are armour. Same two words. Six very different animals.

Take your time

The Studio is where the good ones get made

Out in the field you scribble fast, because a castle is coming. In here nobody is coming. Same pencil, bigger ideas, and all the ink you want — ink never runs out.

  • Outline, then colour

    Pen for the shape. Bucket or crayon to fill it in. The shape is what decides how strong the thing turns out.

  • Mirror for symmetry, undo for wobbles

    Mirror draws both halves at once, so the wings match. Undo quietly removes the stroke nobody needs to know about.

  • Save it, then draw it again

    Every design you like goes into your library. Pull it back out whenever you want that one again.

The masterpiece bonus

The game counts what you put in. More strokes and more detail earn a masterpiece bonus, so the creature walks out tougher than a two-minute blob. Close the outline, flood it with the bucket, and that closed, filled body counts as armour.
